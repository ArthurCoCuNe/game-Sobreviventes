# Projeto VHDL (Teste)

Este é um arquivo `README.md` de teste criado no diretório `~/Documentos/VHDL/projeto`.

## Descrição
Projeto para desenvolvimento e simulação de circuitos digitais utilizando VHDL.

## Estrutura Sugerida
- `src/`: Arquivos de código fonte VHDL (`.vhd`, `.vhdl`)
- `tb/`: Testbenches para validação e simulação
- `sim/`: Scripts de simulação e arquivos de forma de onda (`.vcd`, `.ghw`)

## Ferramentas Recomendadas
- **Simulador:** GHDL, ModelSim, QuestaSim ou Vivado
- **Visualizador de Formas de Onda:** GTKWave
